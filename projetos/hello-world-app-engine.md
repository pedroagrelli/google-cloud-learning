# Aplicação Hello World no App Engine

Neste laboratório, fiz o seguinte:

- clonei os exemplos Python do Google Cloud no Cloud Shell;
- entrei na pasta do exemplo `hello_world` para o App Engine Standard com Python 3;
- atualizei a lista de pacotes e preparei um ambiente virtual Python;
- abri a aplicação no navegador e confirmei que ela exibiu **Hello World!**;
- implantei o serviço `default` no App Engine.

Resultado: o deploy foi concluído e o App Engine forneceu uma URL para acessar a aplicação.
